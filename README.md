# 宠物人格与养宠适配测试

两条测试路径：12 道题测出「你的宠物人格」，10 道题算出「最适合你养的宠物」，并给出可折叠的饲养图鉴。

## 特点

- **单文件交付**：HTML、CSS、JS 与背景音乐全部内联，无外部依赖，断网也能完整运行
- **移动端优先**：手机竖屏为主，桌面端自动切换双列排版
- **结果完整**：五维画像、六维雷达、适配榜单、饲养图鉴、可保存的结果海报
- **纯本地运行**：答题数据不联网、不上传、不写本地存储
- **两条路径区分清晰**：人格结果只展示大类与模糊系别，饲养图鉴仅在养宠适配结果页出现

## 文件结构

```
.
├── index.html   # 唯一入口（约 4.4 MB，含内嵌音频）
├── README.md
└── .gitignore
```

`index.html` 即完整应用，不需要 `audio/`、`vendor/` 等额外目录。

## 本地预览

直接双击 `index.html` 用浏览器打开即可。

如需以 HTTP 方式预览，在本目录执行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 部署

### GitHub Pages

1. 新建仓库，把本目录内的全部文件上传到仓库根目录
2. 进入 Settings → Pages
3. Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/(root)`，保存
4. 等待构建完成后访问 `https://<用户名>.github.io/<仓库名>/`

入口固定为 `index.html`，无需额外配置。

### 内网 / 离线

把 `index.html` 放到任意静态服务器目录即可；也可以直接拷贝文件给使用者本地打开。页面没有任何外链请求，不需要配置跨域、代理或域名。

## 兼容性

- Chrome / Edge / Safari / 微信内置浏览器
- 建议 iOS 15+、Android 10+
- 背景音乐受浏览器自动播放策略限制：首次点击或触摸页面后开始播放，右上角按钮可随时开关

## 说明

测试结果用于自我了解，不构成心理诊断、医疗或兽医建议。养宠前请结合居住条件、每日时间、长期预算、家人或室友同意、过敏情况综合判断，并以正规饲养指南与兽医建议为准。
